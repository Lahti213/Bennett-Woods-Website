# Neighborhood photos

1. Drop photos in this folder (JPGs about 1600px wide keep the site fast).
2. List each one in `content.js` under `photos`, for example:

   { src: "photos/entrance-spring.jpg", alt: "Azaleas at the Concord Road entrance", caption: "Spring at the main entrance", credit: "Jane D." },

The gallery section appears on the home page automatically once at least one photo is listed.
Only post photos you have permission to use. Avoid clearly showing house numbers, license plates, or children's faces.
